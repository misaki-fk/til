## 6/8
一つずつ取り出す
```
(1..i).each do |i|
  puts i
end
```
回数分取り出す
```
5.times do |i|
  puts i
end
```
条件が真の間繰り返す
```
i = 1

while i <= 5
  puts i
  i += 1
end
```
値を変換して新しい配列を作る
```
numbers = [1, 2, 3]

result = numbers.map do |n|
  n * 2
end

p result
```
