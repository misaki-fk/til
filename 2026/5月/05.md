## 5/7
#### セキュリティチェックの流れ
入口：何を調べるか決める
  └─ 認証（Devise/LINEログイン）/ 認可 / CSRF / 入力値 / 機密情報 / Gem の脆弱性

中核：自動ツール + 手動レビュー
  ├─ Brakeman（Rails専用の静的解析ツール。コードを読んで穴を探す）
  ├─ bundler-audit（Gemに既知の脆弱性がないか）
  └─ 手動チェック（Strong Parameters / before_action / 機密値の扱い）

出口：レポートにまとめて、優先度順に修正

Brakeman：Rails専用の静的解析ツールで、SQLインジェクションやXSSなど典型的な脆弱性をコードを実行せずに検出できる
